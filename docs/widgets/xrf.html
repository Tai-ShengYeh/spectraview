XRF Element ID — XRF 光譜元素標記

中文

輸入：Data（XRF 能譜，x 軸＝keV）。輸出：Elements（比對表）。

  1. 自動尋峰後，逐峰比對元素特徵譜線（Kα1/Kβ1/Lα1/Lβ1，X-ray Data Booklet 參考值，Na–U 共 55 元素）。
  2. Energy tolerance：能量容差（keV，預設 0.10）；Lines 可限 K 線或 L 線。
  3. 圖上直接標「Fe Kα1」等；比不到的峰標「?」。Elements 表列出每峰的所有候選（含 Δ 能量）。

x 軸需已校正為 keV；若範圍不像 keV 會出現警告。Kβ/Lβ 同時出現可佐證判定。

English

Input: Data (XRF spectrum, x axis in keV). Output: Elements (match table).

  1. Finds peaks, then matches each to element emission lines (Kα1/Kβ1/Lα1/Lβ1, X-ray Data Booklet values, 55 elements Na–U).
  2. Energy tolerance in keV (default 0.10); Lines can restrict to K or L lines.
  3. Peaks are labeled directly ("Fe Kα1"); unmatched peaks get "?". The Elements table lists all candidates per peak with Δ energy.

The x axis must be calibrated in keV; a warning appears if the range looks wrong. A matching Kβ/Lβ line corroborates the assignment.
