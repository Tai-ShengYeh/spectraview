Load Spectra Files — 批次載入光譜檔

中文

輸出：Spectra（合併 Table，每列一條光譜、共同波段）。

  1. Add files… / Add folder… / Add .zip… 加入來源——資料夾會掃描所有光譜檔（可含子資料夾），.zip 免解壓直接讀。
  2. 支援格式：JCAMP-DX（AFFN）、兩欄 CSV/TSV、矩陣 CSV（欄名＝波長、每列一條光譜；或第一欄＝波長、其後每欄一條光譜——SpectraView「合併匯出」兩種版面）、NetCDF .cdf/.nc（classic 格式，如 applewine 等 chemometrics 資料集、ANDI 層析匯出）。
  3. 右側疊圖預覽；輸出接 Similarity / Library / PLS-DA / Data Table。

NetCDF 讀法：取檔內最大的 2 維數值變數當資料矩陣（每列一條光譜），自動找長度相符的一維變數（wavelength/wavenumber/time…）當 x 軸。無法解析的檔案會略過並提示。

English

Output: Spectra (one merged Table, one spectrum per row on the shared grid).

  1. Add files… / Add folder… / Add .zip… — folders are scanned for all spectra files (optionally recursive); .zip archives are read without extraction.
  2. Formats: JCAMP-DX (AFFN), two-column CSV/TSV, matrix CSV (wavelengths as column names, one spectrum per row; or a wavelength column with one spectrum per further column — both SpectraView "combined export" layouts), and NetCDF .cdf/.nc (classic format, e.g. chemometrics datasets like applewine, ANDI chromatography exports).
  3. The plot previews everything; feed the output to Similarity / Library / PLS-DA / Data Table.

NetCDF strategy: the largest 2-D numeric variable becomes the data matrix (rows = spectra) with a matching 1-D variable (wavelength/wavenumber/time…) as the x-axis. Unparseable files are skipped with a warning.
