Spectra Similarity — 光譜相似度

中文

輸入：Data、References（可省略）。輸出：Scores（逐對分數表）。

  1. 接 Data＋References：算 Data × References 每一對的 correlation / cosine / SAM / Euclidean。
  2. 只接 Data：組內兩兩互比。
  3. correlation / cosine 越大越像；SAM / Euclidean 越小越像。

兩譜會先取重疊波段、內插到共同格點再比較；無重疊會報錯。

English

Inputs: Data, References (optional). Output: Scores (per-pair table).

  1. With Data + References: scores every Data × References pair by correlation / cosine / SAM / Euclidean.
  2. Data only: all pairs within Data are compared.
  3. Higher is more similar for correlation / cosine; lower for SAM / Euclidean.

Spectra are interpolated onto their overlapping range first; no overlap raises an error.
