PLS-DA — 偏最小平方判別分析

中文

輸入：Data（含類別 target 的光譜 Table）。輸出：Scores、Loadings、VIP、Predictions。

  1. 資料要有類別變數（target/class）——用 Select Columns 把類別欄拖到 Target。
  2. 類別 one-hot 後做 PLS2（NIPALS）；分數圖依類別上色，標題顯示訓練準確率。
  3. VIP（variable importance in projection）>1 常視為重要波數——接 Data Table 看哪些波段區分類別。
  4. Predictions 輸出＝原表＋預測類別 meta，接 Confusion Matrix 等 widget 評估。

顯示的是訓練集準確率；要真實效能請接 Orange 的 Test & Score 用交叉驗證（搭配其他學習器比較）。

English

Input: Data (spectra table with a categorical target). Outputs: Scores, Loadings, VIP, Predictions.

  1. The data needs a class variable — use Select Columns to move it to Target.
  2. Classes are one-hot encoded and fit with PLS2 (NIPALS); the scores plot is colored by class with training accuracy in the title.
  3. VIP (variable importance in projection) > 1 is commonly read as an important wavenumber — inspect via Data Table.
  4. Predictions = the input table + a predicted-class meta; feed it to Confusion Matrix for evaluation.

The reported accuracy is on the training set; for honest performance use cross-validation (Orange's Test & Score).
