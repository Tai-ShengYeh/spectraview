Peak Finder — 波峰偵測與標記

中文

輸入：Data（光譜 Table）。輸出：Peaks（position, height, FWHM, prominence, area）。

  1. 調 Min height／Min prominence（皆為訊號全幅的 %）過濾雜訊小峰；Min distance 避免相鄰重複峰。
  2. Smoothing window（Savitzky-Golay 點數，0＝關）只用於偵測，峰高仍讀原始訊號。
  3. 圖上自動以三角形＋數字標記峰位；Peaks 表接 Data Table 檢視或存檔。

與 SpectraView 桌面版 Analyze ▸ Find peaks 相同演算法（scipy find_peaks＋半高寬）。

English

Input: Data (spectra table). Output: Peaks (position, height, FWHM, prominence, area).

  1. Tune Min height / Min prominence (both % of full range) to reject noise; Min distance merges close duplicates.
  2. Smoothing window (Savitzky-Golay points, 0 = off) affects detection only — heights are read from the raw signal.
  3. Peaks are marked with a triangle + position label; view the Peaks table in Data Table.

Same algorithm as SpectraView desktop's Analyze ▸ Find peaks (scipy find_peaks + FWHM at half height).
