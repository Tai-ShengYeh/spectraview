Spectrometer — 影像分光（相機＋光柵）

中文

輸出：Spectra（單一光譜的 Table）。

  1. 按 Choose spectrum photo… 選一張『相機＋繞射光柵』拍到的光譜照片（光譜是水平展開的彩色條）。
  2. Channel：luminance（預設）／R／G／B／sum；Strip centre / height 選要取的水平帶（避開過曝或雜訊列）。
  3. Wavelength calibration：填 像素=波長 對（每行或逗號分隔），例如日光燈汞線 120=435.8, 410=546.1, 560=611.6；選 linear 或 quadratic 擬合。留空則 x 軸維持像素。
  4. 上圖顯示照片與選取帶、下圖是萃取出的光譜；輸出接 Similarity / Library / Peak Finder / Data Table。

等效於 Theremino Spectrometer 的核心：取水平帶 → 沿水平讀強度 → 用已知譜線把像素校準成波長。用同一盞校準燈拍照，之後同機況的照片可沿用同一組校準點。

English

Output: Spectra (a single-spectrum Table).

  1. Click Choose spectrum photo… and pick a photo from a camera + diffraction grating (the spectrum is a horizontal colour band).
  2. Channel: luminance (default) / R / G / B / sum; Strip centre / height select the horizontal band to read (avoid over-exposed or noisy rows).
  3. Wavelength calibration: enter pixel=nm pairs (per line or comma-separated), e.g. a fluorescent lamp's mercury lines 120=435.8, 410=546.1, 560=611.6; fit linear or quadratic. Leave empty to keep the x-axis in pixels.
  4. The top panel shows the photo with the ROI band; the bottom is the extracted spectrum. Feed the output to Similarity / Library / Peak Finder / Data Table.

This is the core of a Theremino-style spectrometer: take a horizontal strip → read intensity along it → calibrate pixel → wavelength from known lines. Shoot one calibration lamp; later photos taken with the same setup can reuse the same calibration points.
