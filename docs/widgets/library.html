Spectral Library — 光譜庫建立與比對

中文

輸入：Spectra（入庫）、Query（未知譜）。輸出：Hits（排名）、Best Match、Library。

  1. 參考譜接 Spectra → Add input spectra to library。
  2. Save…/Load… 讀寫 .speclib（與 SpectraView 桌面版互通，例：repo 的 examples/sugars_nir.speclib）。
  3. 未知譜接 Query → Hits 是對整庫的排名表；Library 輸出可直接當 Mixture Analysis 的參考譜。
English

Inputs: Spectra (to add), Query (unknowns). Outputs: Hits (ranking), Best Match, Library.

  1. Feed references to Spectra → Add input spectra to library.
  2. Save…/Load… read/write .speclib (interoperable with the SpectraView desktop app, e.g. examples/sugars_nir.speclib).
  3. Feed unknowns to Query → Hits ranks them against the whole library; the Library output feeds Mixture Analysis directly.
