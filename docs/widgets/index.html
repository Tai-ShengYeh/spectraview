orange-spectra — widget help 說明文件

在 Orange 中選取 widget 後按 F1（或狀態列的 ?）就會開啟對應頁面。 Press F1 on a selected widget in Orange to open its page here.

  • Import Spectrum URL — 從網址匯入光譜
  • Spectra Similarity — 光譜相似度
  • Spectral Library — 光譜庫建立與比對
  • Mixture Analysis — 混合光譜成分分析
  • Aquagram — 水光譜學雷達圖
  • Peak Finder — 波峰偵測與標記
  • XRF Element ID — XRF 光譜元素標記
  • PLS-DA — 偏最小平方判別分析
