Merge Spectra — 多光譜疊圖合併

中文

輸入：Spectra（可接多個來源）。輸出：Spectra（合併後的 Table）。

  1. 把多個光譜來源接到 Spectra 輸入——多個 Import Spectrum URL、File、或任何欄名＝波數的 Table。
  2. 右側把所有光譜疊在同一張圖；Normalize each 可選 none / max=1 / area=1 / SNV（讓不同強度的譜可比較）。
  3. Stack offset 只影響顯示（把每條往上錯開，方便看形狀），不改輸出數值。
  4. 輸出是一個合併 Table（每列一條光譜、共同重疊波段），可再接 Similarity / Library / Mixture / PLS-DA。

合併輸出會取所有光譜的重疊波段內插到共同格點（與 SpectraView 的「合併匯出」一致）；完全沒有重疊才會報錯。

English

Input: Spectra (connect several sources). Output: Spectra (one combined Table).

  1. Connect several spectra sources to Spectra — multiple Import Spectrum URL widgets, File, or any wavenumber-column Table.
  2. All spectra overlay on one plot; Normalize each = none / max=1 / area=1 / SNV so differently-scaled spectra are comparable.
  3. Stack offset affects display only (spreads curves vertically), not the output values.
  4. The output is one combined Table (each row a spectrum on the shared overlap grid), ready for Similarity / Library / Mixture / PLS-DA.

The combined output uses the overlap region of all spectra, interpolated to a common grid (like SpectraView's combined export); no overlap raises an error.
