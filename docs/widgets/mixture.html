Mixture Analysis — 混合光譜成分分析

中文

輸入：Mixture（混合譜）、References（參考譜）。輸出：Composition（成分表）、Fit（擬合譜）。

  1. 混合譜接 Mixture、參考譜（或 Spectral Library 的 Library 輸出）接 References。
  2. 非負最小平方（NNLS）解 mixture ≈ Σ cᵢ·refᵢ，回報係數、百分比與 R²，並疊出擬合曲線與殘差。

參考譜需涵蓋混合譜的波段；建議先做基線校正。

English

Inputs: Mixture, References. Outputs: Composition (table), Fit (fitted spectrum).

  1. Connect the mixed spectrum to Mixture and reference spectra (or the Library output) to References.
  2. Non-negative least squares solves mixture ≈ Σ cᵢ·refᵢ, reporting coefficients, percentages and R², with fit + residual overlay.

References should cover the mixture's range; baseline-correct first for best results.
