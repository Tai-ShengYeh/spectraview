Import Spectrum URL — 從網址匯入光譜

中文

輸出：Spectra（Table，每列一條光譜、欄名＝波數）。

  1. 貼上 IRUG 編號（如 4119）、IRUG/SOPRANO 頁面網址，或 JCAMP-DX（AFFN）/兩欄 CSV 的直接網址。
  2. 按 Fetch & add：下載、解析、畫圖。重複 Fetch 可累積多條（自動重採樣到共同波段）。
  3. 輸出接 Data Table、Orange-Spectroscopy 的 Spectra 檢視或本分類其他 widget。

IRUG 網頁沒有下載檔——光譜藏在頁面 jqPlot 圖的 script 裡；SOPRANO 藏在 Dygraph 陣列。widget 直接解析網頁原始碼。

English

Output: Spectra (Table, one spectrum per row, wavenumbers as columns).

  1. Paste an IRUG id (e.g. 4119), an IRUG/SOPRANO page URL, or a direct JCAMP-DX (AFFN) / two-column CSV URL.
  2. Click Fetch & add — download, parse, plot. Fetch again to accumulate spectra (resampled to a common range).
  3. Connect the output to Data Table, Orange-Spectroscopy's viewers, or the other Spectra widgets.

IRUG pages have no download file — the spectrum is embedded in the page's jqPlot script; SOPRANO embeds a Dygraph array. The widget parses the page source directly.
