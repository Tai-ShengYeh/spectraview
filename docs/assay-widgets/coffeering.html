Coffee-Ring Reader — 咖啡環讀取

中文

輸出：Cells（正規化時：concentration, ratio, se, col；未正規化時逐格 value）。

  1. 選點樣／咖啡環盤照片。
  2. 設 Rows（重複列）與 Columns（第 0 欄＝blank）；可勾 Auto-detect grid 從亮點自動抓格。
  3. Measure：thresholded count 或 intensity；Threshold：manual（預設 0.43）/ Otsu / per-cell Otsu。
  4. 勾 Divide by blank：每格除以同列第 0 欄、再平均重複列；Concentrations 填第 1 欄起的濃度。
  5. Cells 輸出接 Dose-Response Fit 求 EC50 / LOD。

重現 coffee-ring-analyzer：ITU-R 601 灰階、integral image 逐格量測、blank 正規化——與其 Streamlit／手機／CLI 版結果一致。

English

Output: Cells (normalized: concentration, ratio, se, col; or per-cell value when raw).

  1. Choose the spotted-assay / coffee-ring plate photo.
  2. Set Rows (replicates) and Columns (column 0 = blank); tick Auto-detect grid to find cells from bright spots.
  3. Measure: thresholded count or intensity; Threshold: manual (default 0.43) / Otsu / per-cell Otsu.
  4. Tick Divide by blank to normalize each cell by its row's column 0 and average replicate rows; fill in Concentrations for columns 1…
  5. Feed Cells to Dose-Response Fit for EC50 / LOD.

Reproduces coffee-ring-analyzer: ITU-R 601 grayscale, integral-image per-cell measurement, blank normalization — matching its Streamlit / mobile / CLI results.
