Dose-Response Fit — 劑量反應曲線擬合

中文

輸入：任何含濃度與訊號兩數值欄的 Table。輸出：Fit summary（參數＋EC50/LOD/R²）、Fitted curve。

  1. 選 Concentration 與 Signal 兩欄；濃度跨數量級時勾 log10。
  2. Model：3PL（y = L/(1+e^-k(x-x0))）或 4PL（多下/上漸近線）。
  3. 讀 EC50（＝拐點 x0）、LOD（訊號超過基線＋3σ 的濃度）、R²；曲線疊在資料點上。
  4. Fit summary 接 Data Table 檢視；Fitted curve 可疊圖。

這是共用 widget：Microplate / Coffee-Ring Reader 的輸出、或任何比色法/ELISA 數據都能接。

English

Input: any Table with a concentration column and a signal column. Outputs: Fit summary (params + EC50/LOD/R²), Fitted curve.

  1. Pick the Concentration and Signal columns; tick log10 when concentrations span orders of magnitude.
  2. Model: 3PL (y = L/(1+e^-k(x-x0))) or 4PL (explicit lower/upper asymptotes).
  3. Read EC50 (= inflection x0), LOD (concentration where signal exceeds baseline + 3σ), and R²; the curve overlays the points.
  4. Feed Fit summary to a Data Table; overlay Fitted curve as needed.

This is the shared widget: it accepts either reader's output, or any colorimetric / ELISA data you already have.
